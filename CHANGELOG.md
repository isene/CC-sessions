# Changelog

## [1.0.0] - 2025-01-23

### Added
- Initial release
- `cc` command to manage Claude Code sessions
- `/bm` slash command for bookmarking sessions with tags
- `cc <tag>` to resume session by tag
- `cc -l` to list all bookmarked sessions
- `cc -h` for help
- Auto-install of `/bm` command on first run
